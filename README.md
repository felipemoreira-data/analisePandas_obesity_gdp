# 📊 Projeto de Análise de Dados com Pandas

## 📌 Descrição
Este projeto realiza uma análise simples de dados utilizando Python e a biblioteca Pandas, com foco na limpeza e extração de dados relevantes de dois conjuntos de dados (Índice de obesidade por países no decorrer dos anos) e (Evolução do PIB per Capita dos países no decorrer dos anos).

O objetivo é aplicar conceitos de:
- Limpeza de dados
- Análise estatística
- Visualização de dados simples

---

## 🛠 Tecnologias utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Google Colab
